## 6. Limitations paragraph (`main.tex:214`) additions

- GPU training is not bit-for-bit repeatable: the deployed Task 1 checkpoint is a retrain of seed 42 (dev weighted F1 0.8289 against 0.8321 originally, best epoch 3 against 2), 94.3% test-prediction agreement with the original run; same-seed variation (0.0032) exceeds the inter-seed dev spread (0.0030), so the choice of seed is within noise. Architecture claims use the 3-seed means.
- The Task 1 and Task 2 splits overlap by tweet; Task 1 models use no Task 2 artifacts (asserted), but any new model that did would be contaminated.
- Differences between arms are mostly within the seed spread; "better" is used only where a paired dev interval excludes 0.
- Test intervals are reported after the dev decision and were never used to choose; where dev and test disagree on resolvability (the Task 1 fusion gains), dev wins.
- Latency was measured on one laptop with three fixed examples.
- Error-analysis categories are rule-based.
