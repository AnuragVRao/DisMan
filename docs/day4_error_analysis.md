# Day 4 error analysis (12 misclassified test examples per task)
Selection is rule-based and fixed in advance (see the docstring of `ablation/d4_error_analysis.py`): the population is every test row the deployed model gets wrong; each error is assigned to the first matching category (text-image mismatch, then label ambiguity, then model error); the sample is the first 4 errors by test-row index per category (shortfalls filled in category order). **Categories are assigned by rule, not by human inspection**: *text-image mismatch* means the row's text label and image label disagree; *label ambiguity* means the calibrated Task 1 top probability is below 0.65, or, for Task 2, the (true, predicted) pair is one of four pre-declared confusable pairs; everything else is *model error*. A reviewer should read the examples before quoting any category as a cause.
