# Day 4 error analysis (12 misclassified test examples per task)
Rule fixed before any example was looked at (SELECTION_RULE_DAY4.md rule 22): the population is every test row the model gets wrong; the (true, predicted) pairs are ranked by error count, and from each pair in rank order the first rows by test-row index are taken (at most 3 per pair; 6 for Task 1, which has only two pairs) until 12 are collected. Each error gets the first matching category: *text-image mismatch* (the row's text label differs from its image label); *label ambiguity* (the predicted class is the true class's most-confused partner AND the example is near-duplicate-like, i.e. has a near-identical train example with a conflicting label, or generic, i.e. at most 5 words after normalisation); otherwise *model error*. **The categories come from these written criteria, not from reading each example**; the counts over all errors are given so that the 12 can be judged for representativeness.
