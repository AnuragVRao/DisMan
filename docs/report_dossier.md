## 5. Deviations and caveats

- **Retrained deployed checkpoint.** Seed 42 was retrained with `--save` because the original runs saved no weights: dev weighted F1 0.8289 vs 0.8321, best epoch 3 vs 2, 94.3% test-prediction agreement. Same-seed run-to-run variation (0.0032) exceeds the inter-seed dev spread (0.0030), so seed selection is within noise. Quote the deployed numbers from `bertweet_deploy`, architecture claims from the 3-seed means.
- **Post-hoc arms** (labelled * in the tables): balanced NB, Complement NB, majority class, unweighted BERTweet, BERTweet + CLIP B/32 (backbone swap), the paired BERTweet-vs-DistilBERT bootstrap, the BiLSTM-vs-TF-IDF bootstrap. Pre-registered rules: `ablation/SELECTION_RULE_DAY4.md` (rules 1-24).
- **Borderline results.** Switch rule lower bound only +0.0049; BERTweet vs DistilBERT dev macro-F1 interval [-0.0004, +0.0334] (marginally includes zero); core model vs L4a / vs the CLIP B/32 head on dev macro-F1 are not distinguishable (weighted F1 is worse, secondary).
- **Dev/test disagreement.** Task 1 fusion and the core model are better than text-only on test intervals (lower bounds +0.001 to +0.002) but not on dev; the rule uses dev. Task 2 core model is worse than L4a on test macro-F1 (interval excludes 0) but not on dev macro-F1.
- **Tie-break basis.** Rules 14-19 of SELECTION_RULE_DAY4.md contain no tie wording; rule 2 ("Ties go to the simplest model") governs, with "simplest" = fewest trainable parameters as in the Day 2 addendum: core model 135,755,784, L4a 67,352,840, image-only B/32 head 199,688.
- **Agreed/disagreed numbers are descriptive** (no interval); the Task 2 subset macro-F1 averages the classes present (Table VIII definition; L4a reproduces 0.745 and 0.549).
- **Error analysis categories are rule-based** (written criteria, not reading each example); the ambiguity criterion fires rarely (T1 8, T2 3 errors); one sampled Task 2 tweet contains a vulgar word verbatim from the data.
- **Optional candidates not run:** DeBERTa-v3, ModernBERT, SigLIP, EfficientNet-B0, zero-shot VLM/LLM, ResNet50 fine-tuning, Task 1 gated fusion, BERTweet inside the L4a cross-attention.
- **Not compiled.** No LaTeX engine is installed; the compiler binary I downloaded was blocked by the sandbox. `report_v2/main.tex` passes `ablation/d4_check_tex.py` (matched environments, labels, citations, figure files) but overfull boxes and undefined-reference warnings from a real compile are unchecked.
- **Wrong draft corrected.** The first `docs/day4_report_changes.md` targeted `report/main.tex`; it was rewritten for `Capstone_report_Sem5.tex`.
